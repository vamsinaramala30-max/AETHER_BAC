# AETHER Platform - Backend Core Infrastructure

Welcome to the backend infrastructure repository for the **AETHER Platform**. This project is built using Node.js, Express.js, TypeScript, Prisma ORM, PostgreSQL (with `pgvector`), Redis, and Supabase.

---

## Tech Stack

- **Runtime:** Node.js (v20+)
- **Framework:** Express.js
- **Language:** TypeScript (Strict Mode)
- **Database:** PostgreSQL (with `pgvector` extension)
- **ORM:** Prisma
- **Cache & Queue:** Redis + BullMQ
- **Real-Time:** Socket.IO
- **Storage & Auth Extras:** Supabase / Google OAuth / JWT
- **AI Engine:** Google Gemini AI
- **Logging:** Winston + Daily Rotate File
- **Containerization:** Docker & Docker Compose
